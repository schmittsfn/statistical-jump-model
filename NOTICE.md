# Provenance

This standalone statistical jump model implementation was split from
[schmittsfn/risk-model-replications](https://github.com/schmittsfn/risk-model-replications)
at commit `b8afcda`. The model code and reference fixtures retain the same
calculations; imports are relocated into the standalone package. Only this
model's helpers, dependencies and synthetic example are included.

The cited papers are linked rather than redistributed. Third-party numerical
libraries are dependencies, not vendored or relicensed. Tests and documentation
were prepared with OpenAI Codex assistance. The cited authors have not endorsed
this project. Original data and private development archives are not included.
